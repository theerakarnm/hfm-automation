# Simple-trade deposit match and idle wallet alert Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For the simple-trade tenant only, match an account when its cumulative deposits are above 30 USD, show a partial match on the lookup card, notify the bot recipients once per new match, and notify once per wallet that has not traded for more than 21 days.

**Architecture:** One codebase. Behaviour is chosen by two new per-tenant vars (`MATCH_RULE`, `IDLE_ALERT_DAYS`).
The rules are pure functions over a joined account list, so a future tenant changes a var, not code.
A new daily Cloudflare cron (`30 17 * * *`, which is 00:30 in Bangkok) fetches the HFM data once and runs both scans.
State lives in two new Postgres tables, because a Worker isolate can be evicted between ticks.

**Tech Stack:** Cloudflare Workers (cron triggers, Hyperdrive), Hono, Drizzle ORM + PostgreSQL, Bun test, TypeScript strict.

**Base branch:** `feature/migration-cf-worker`. This work builds on the Worker code. It does not exist on `main`.

| # | Decision |

| 1 | The daily job runs at 00:30 Bangkok time. Cloudflare cron is UTC, so the schedule is `30 17 * * *`. |
| 2 | Applies to simple-trade only. maow keeps today's behaviour. |
| 3 | The match basis is the cumulative `deposits` of a single account, not a wallet total. |
| 4 | The lookup card for simple-trade uses the new rule instead of the balance rule. |
| 5 | Match All = under `TARGET_WALLET` and `deposits > 30` (USD) or `deposits / 100 > 30` (USC). `deposits > 30` under another partner shows **Partial Match** with the reason "TARGET_WALLET does not match". |
| 6 | The idle alert is per wallet, only for wallets under `TARGET_WALLET`. It uses the latest `last_trade` of the wallet's accounts, falls back to `first_funding` when the wallet never traded, and skips wallets with neither. |
| handoff 2026-10-17 | `>` not `>=`. Only USD and USC qualify (THB and EUR do not). The first run records already-matched accounts silently. Notify once per crossing. Recipients are the existing active recipients through `pushToAll`. |

## Assumptions made without asking (change them if wrong)

- Both scans run in the same daily job. A new match is reported up to a day late. Moving the match scan to the `*/5` tick later only changes `dispatchCron`.
- The first match run is silent (handoff default). The first idle run is not silent: it sends one message with at most 30 wallets, longest idle first, plus "and N more".
- One LINE message per scan per run, not one per account.
- HFM times such as `2026-09-07 19:12:55` are read as UTC. A few hours of error does not matter against a 21 day limit.
- The deposits rule reuses `DEPOSIT_THRESHOLD_USD` (set to 30) and `DEPOSIT_THRESHOLD_USC` (set to 3000, in cents) with a strict `>`. The balance rule keeps `>=`.
- maow also gets the new daily cron, because `tests/tenant-config.test.ts` requires identical triggers. For maow the job returns at once (`MATCH_RULE=balance`, `IDLE_ALERT_DAYS=0`).

```ts
// Which condition decides the deposit half of "Match". "balance" is the
// original rule (current balance >= threshold). "deposits" is cumulative
// deposits strictly above the threshold, USD and USC accounts only. Read per
// call for the same reason as the other flags: Bun caches the module.
export type MatchRule = "balance" | "deposits";

export function getMatchRule(): MatchRule {
  const raw = (process.env.MATCH_RULE ?? "").trim().toLowerCase();
  return raw === "deposits" ? "deposits" : "balance";
}

// Days without a trade before a wallet is reported. Anything that is not a
// positive whole number (including unset) turns the idle alert off.
export function getIdleAlertDays(): number {
  const parsed = Number((process.env.IDLE_ALERT_DAYS ?? "").trim());
  return Number.isInteger(parsed) && parsed > 0 ? parsed : 0;
}

// Cumulative deposits strictly above the per-currency threshold. USC deposits
// arrive in cents and DEPOSIT_THRESHOLD_USC is in cents too, so one comparison
// serves both. THB, EUR and any other currency never qualify.
export function depositsExceedThreshold(
  deposits: number | string | null | undefined,
  accountCurrency: string,
): boolean {
  if (accountCurrency !== "USD" && accountCurrency !== "USC") return false;
  return toNum(deposits) > getDepositThreshold(accountCurrency);
}
```

```ts
import { depositsExceedThreshold, extractWalletNumber } from "./hfm.service";
import type { HFMClientRow, HFMPerformanceData } from "../types/hfm.types";

const DAY_MS = 24 * 60 * 60 * 1000;

/** One HFM account with the fields both daily scans need. */
export interface ScanAccount {
  accountId: number;
  /** The client wallet (HFM `client_id` / `wallet`). */
  walletId: number;
  /** The partner the account sits under, compared with TARGET_WALLET. */
  partnerId: number | null;
  currency: string;
  deposits: number;
  lastTrade: string | null;
  firstFunding: string | null;
}

export interface IdleWallet {
  walletId: number;
  lastActivityAt: string;
  basis: "last_trade" | "first_funding";
  idleDays: number;
}

// HFM sends "YYYY-MM-DD HH:mm:ss" without a zone. Read as UTC: a few hours of
// error does not matter against a 21 day limit.
export function parseHfmTime(value: string | null | undefined): number | null {
  if (!value) return null;
  const ms = Date.parse(`${value.trim().replace(" ", "T")}Z`);
  return Number.isNaN(ms) ? null : ms;
}

/**
 * Joins the two HFM payloads on the account id. The performance endpoint is
 * the source of partner, currency and deposits, so the daily scan and the
 * lookup card judge the same numbers. /api/clients/ adds the trade dates the
 * performance endpoint does not carry.
 */
export function joinScanAccounts(
  performance: HFMPerformanceData[],
  clients: HFMClientRow[],
): ScanAccount[] {
  const byId = new Map(clients.map((c) => [c.id, c]));
  return performance
    .filter((p) => !p.archived)
    .map((p) => {
      const row = byId.get(p.account_id);
      return {
        accountId: p.account_id,
        walletId: p.client_id,
        partnerId: extractWalletNumber(String(p.subaffiliate)),
        currency: p.account_currency,
        deposits: Number(p.deposits ?? 0) || 0,
        lastTrade: row?.last_trade ?? null,
        firstFunding: row?.first_funding ?? null,
      };
    });
}

export function matchedAccounts(
  accounts: ScanAccount[],
  targetPartner: number,
): ScanAccount[] {
  return accounts.filter(
    (a) =>
      a.partnerId === targetPartner &&
      depositsExceedThreshold(a.deposits, a.currency),
  );
}

function latest(values: (string | null)[]): { ms: number; text: string } | null {
  let best: { ms: number; text: string } | null = null;
  for (const text of values) {
    const ms = parseHfmTime(text);
    if (ms !== null && text !== null && (best === null || ms > best.ms)) {
      best = { ms, text };
    }
  }
  return best;
}

/**
 * Wallets under the target partner whose last activity is more than `days`
 * days old. Activity is the latest last_trade over the wallet's accounts.
 * A wallet that never traded counts from its first funding. A wallet with
 * neither is skipped. Longest idle first.
 */
export function idleWallets(
  accounts: ScanAccount[],
  targetPartner: number,
  nowMs: number,
  days: number,
): IdleWallet[] {
  const wallets = new Map<number, ScanAccount[]>();
  for (const a of accounts) {
    if (a.partnerId !== targetPartner) continue;
    const list = wallets.get(a.walletId);
    if (list) list.push(a);
    else wallets.set(a.walletId, [a]);
  }

  const out: IdleWallet[] = [];
  for (const [walletId, list] of wallets) {
    const trade = latest(list.map((a) => a.lastTrade));
    const found = trade ?? latest(list.map((a) => a.firstFunding));
    if (!found) continue;
    const idleMs = nowMs - found.ms;
    if (idleMs <= days * DAY_MS) continue;
    out.push({
      walletId,
      lastActivityAt: found.text,
      basis: trade ? "last_trade" : "first_funding",
      idleDays: Math.floor(idleMs / DAY_MS),
    });
  }
  return out.sort((a, b) => b.idleDays - a.idleDays);
}
```

```ts
import { inArray, notInArray } from "drizzle-orm";
import type { DrizzleDb } from "../db/connection";
import { accountMatchState, walletIdleAlerts } from "../db/schema";

// INSERT ... ON CONFLICT DO NOTHING RETURNING is atomic in PostgreSQL, so the
// ids it returns were claimed by this call and by no other. Hyperdrive runs
// with caching disabled, so a cached read cannot hide a row.

export async function claimNewMatches(
  db: DrizzleDb,
  accountIds: number[],
): Promise<number[]> {
  if (accountIds.length === 0) return [];
  const rows = await db
    .insert(accountMatchState)
    .values(accountIds.map((accountId) => ({ accountId })))
    .onConflictDoNothing()
    .returning({ accountId: accountMatchState.accountId });
  return rows.map((r) => r.accountId);
}

export async function releaseMatches(
  db: DrizzleDb,
  accountIds: number[],
): Promise<void> {
  if (accountIds.length === 0) return;
  await db
    .delete(accountMatchState)
    .where(inArray(accountMatchState.accountId, accountIds));
}

export async function claimIdleAlerts(
  db: DrizzleDb,
  walletIds: number[],
): Promise<number[]> {
  if (walletIds.length === 0) return [];
  const rows = await db
    .insert(walletIdleAlerts)
    .values(walletIds.map((walletId) => ({ walletId })))
    .onConflictDoNothing()
    .returning({ walletId: walletIdleAlerts.walletId });
  return rows.map((r) => r.walletId);
}

export async function releaseIdleAlerts(
  db: DrizzleDb,
  walletIds: number[],
): Promise<void> {
  if (walletIds.length === 0) return;
  await db
    .delete(walletIdleAlerts)
    .where(inArray(walletIdleAlerts.walletId, walletIds));
}

/** Deletes the open alerts of wallets that are no longer idle. Returns how many. */
export async function clearRecoveredIdleAlerts(
  db: DrizzleDb,
  stillIdleWalletIds: number[],
): Promise<number> {
  const rows =
    stillIdleWalletIds.length === 0
      ? await db
          .delete(walletIdleAlerts)
          .returning({ walletId: walletIdleAlerts.walletId })
      : await db
          .delete(walletIdleAlerts)
          .where(notInArray(walletIdleAlerts.walletId, stillIdleWalletIds))
          .returning({ walletId: walletIdleAlerts.walletId });
  return rows.length;
}
```

```ts
import type { IdleWallet, ScanAccount } from "../services/scan-rules";

// One LINE text is limited to 5,000 characters. 30 lines of about 60
// characters stay far below that, and the footer says what was cut.
const MAX_LINES = 30;

// USC deposits arrive in cents.
function formatDeposits(deposits: number, currency: string): string {
  const value = currency === "USC" ? deposits / 100 : deposits;
  return `${value.toLocaleString("en-US", {
    minimumFractionDigits: 2,
    maximumFractionDigits: 2,
  })} ${currency}`;
}

export function buildMatchMessage(
  accounts: ScanAccount[],
  thresholdUsd: number,
): string {
  const lines = accounts
    .slice(0, MAX_LINES)
    .map(
      (a) =>
        `• T${a.accountId} (wallet ${a.walletId}) ฝากสะสม ${formatDeposits(a.deposits, a.currency)}`,
    );
  const more = accounts.length - lines.length;
  return [
    `✅ Match ใหม่ ${accounts.length} บัญชี (ยอดฝากสะสมเกิน ${thresholdUsd} USD)`,
    ...lines,
    ...(more > 0 ? [`และอีก ${more} บัญชี`] : []),
  ].join("\n");
}

export function buildIdleMessage(wallets: IdleWallet[], days: number): string {
  const lines = wallets.slice(0, MAX_LINES).map((w) => {
    const date = w.lastActivityAt.slice(0, 10);
    return w.basis === "last_trade"
      ? `• ${w.walletId} - เทรดล่าสุด ${date} (${w.idleDays} วัน)`
      : `• ${w.walletId} - เติมเงินครั้งแรก ${date} ยังไม่เคยเทรด (${w.idleDays} วัน)`;
  });
  const more = wallets.length - lines.length;
  return [
    `⚠️ ${wallets.length} wallet ไม่เทรดเกิน ${days} วัน`,
    ...lines,
    ...(more > 0 ? [`และอีก ${more} wallet`] : []),
  ].join("\n");
}
```

```ts
import { getDb, type DrizzleDb } from "../db/connection";
import { getJobState, setJobState } from "../db/state.repository";
import { resolveNotifyUids } from "../repositories/recipient.repository";
import {
  claimIdleAlerts,
  claimNewMatches,
  clearRecoveredIdleAlerts,
  releaseIdleAlerts,
  releaseMatches,
} from "../repositories/scan-state.repository";
import {
  fetchAllClients,
  fetchClients,
  getDepositThreshold,
  getIdleAlertDays,
  getMatchRule,
} from "../services/hfm.service";
import { pushToAll } from "../services/line.service";
import {
  idleWallets,
  joinScanAccounts,
  matchedAccounts,
  type ScanAccount,
} from "../services/scan-rules";
import { logError, logInfo } from "../utils/logger";
import { buildIdleMessage, buildMatchMessage } from "./scan-messages";

export const MATCH_BASELINE_KEY = "deposit_match:baselined";

// Both payloads are about 1.5 MB and /api/clients/ alone takes ~7s. A cron has
// no reply token to protect, so the budget is generous.
const FETCH_TIMEOUT_MS = 60_000;

export interface DailyScanOptions {
  db?: DrizzleDb;
  nowMs?: () => number;
  fetchAllClientsFn?: typeof fetchAllClients;
  fetchClientsFn?: typeof fetchClients;
  getUidsFn?: (db: DrizzleDb) => Promise<string[]>;
  pushToAllFn?: (uids: string[], text: string) => Promise<void>;
}

interface StepDeps {
  db: DrizzleDb;
  getUids: (db: DrizzleDb) => Promise<string[]>;
  pushAll: (uids: string[], text: string) => Promise<void>;
}

// Each scan has its own try: a failure in one must not skip the other.
async function guarded(step: string, fn: () => Promise<void>): Promise<void> {
  try {
    await fn();
  } catch (err) {
    logError(`daily-scan:${step}`, err);
  }
}

/**
 * Daily 00:30 Bangkok. Reads two switches from the tenant's vars:
 * MATCH_RULE=deposits turns on the new-match notification, IDLE_ALERT_DAYS > 0
 * turns on the idle wallet alert. With both off it returns before any HFM call.
 */
export async function runDailyScan(options: DailyScanOptions = {}): Promise<void> {
  const matchOn = getMatchRule() === "deposits";
  const idleDays = getIdleAlertDays();
  if (!matchOn && idleDays === 0) return;

  const db = options.db ?? getDb();
  const fetchPerformance = options.fetchAllClientsFn ?? fetchAllClients;
  const fetchClientRows = options.fetchClientsFn ?? fetchClients;
  const deps: StepDeps = {
    db,
    getUids: options.getUidsFn ?? resolveNotifyUids,
    pushAll: options.pushToAllFn ?? pushToAll,
  };

  const [performance, clients] = await Promise.all([
    fetchPerformance(FETCH_TIMEOUT_MS),
    fetchClientRows(FETCH_TIMEOUT_MS),
  ]);
  if (!performance.ok || !clients.ok) {
    logError(
      "daily-scan",
      `HFM fetch failed (performance=${performance.ok ? "ok" : performance.reason}, clients=${clients.ok ? "ok" : clients.reason})`,
    );
    return;
  }

  const target = Number(process.env.TARGET_WALLET);
  const accounts = joinScanAccounts(performance.data.clients, clients.data);

  if (matchOn) {
    await guarded("deposit-match", () => runDepositMatch(deps, accounts, target));
  }
  if (idleDays > 0) {
    const nowMs = (options.nowMs ?? Date.now)();
    await guarded("idle-wallets", () =>
      runIdleWallets(deps, accounts, target, nowMs, idleDays),
    );
  }
}

async function runDepositMatch(
  { db, getUids, pushAll }: StepDeps,
  accounts: ScanAccount[],
  target: number,
): Promise<void> {
  const matched = matchedAccounts(accounts, target);
  const ids = matched.map((a) => a.accountId);

  // First run on this database: record who already qualifies, tell nobody.
  if ((await getJobState(db, MATCH_BASELINE_KEY)) === null) {
    await claimNewMatches(db, ids);
    await setJobState(db, MATCH_BASELINE_KEY, "1");
    logInfo("daily-scan", { baselined: ids.length }, "deposit match baseline recorded");
    return;
  }

  const claimed = await claimNewMatches(db, ids);
  if (claimed.length === 0) return;

  const uids = await getUids(db);
  if (uids.length === 0) {
    logInfo("daily-scan", { matches: claimed.length }, "no active recipients, match not announced");
    return;
  }

  const claimedSet = new Set(claimed);
  const fresh = matched.filter((a) => claimedSet.has(a.accountId));
  try {
    await pushAll(uids, buildMatchMessage(fresh, getDepositThreshold("USD")));
  } catch (err) {
    // Give the claim back so tomorrow's run announces these accounts.
    await releaseMatches(db, claimed);
    throw err;
  }
  logInfo("daily-scan", { matches: claimed.length }, "deposit match announced");
}

async function runIdleWallets(
  { db, getUids, pushAll }: StepDeps,
  accounts: ScanAccount[],
  target: number,
  nowMs: number,
  days: number,
): Promise<void> {
  const idle = idleWallets(accounts, target, nowMs, days);
  const ids = idle.map((w) => w.walletId);

  // Wallets that traded again lose their open alert, so a later idle spell
  // alerts again.
  await clearRecoveredIdleAlerts(db, ids);
  const claimed = await claimIdleAlerts(db, ids);
  if (claimed.length === 0) return;

  const uids = await getUids(db);
  if (uids.length === 0) {
    logInfo("daily-scan", { idle: claimed.length }, "no active recipients, idle wallets not announced");
    return;
  }

  const claimedSet = new Set(claimed);
  const fresh = idle.filter((w) => claimedSet.has(w.walletId));
  try {
    await pushAll(uids, buildIdleMessage(fresh, days));
  } catch (err) {
    await releaseIdleAlerts(db, claimed);
    throw err;
  }
  logInfo("daily-scan", { idle: claimed.length }, "idle wallets announced");
}
```
